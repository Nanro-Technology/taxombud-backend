Roles, Lookups, Audit Logs, Settings, Webhooks, Health
Roles (8), Lookups (16), Audit Logs (4), Settings (11), Webhooks (8), Health (4) 51 ~38 ~13 Spec specifies 51 across these six sections but the .md says "implement all as specified" without listing them individually. Based on JSON count, most are partially covered. Lookups only has 1 endpoint (GET /lookups/{type}). Audit logs has 2 (vs 4 spec). Settings has ~5 (vs 11). HR endpoints (staff, leave, payroll, pay grades) appear in JSON but are NOT in the spec's controller endpoint tables — these are extra additions.
Additional JSON endpoints not in the spec: /api/v1/auth/register, POST /api/v1/officers, PUT /api/v1/officers/{id}, POST /taxpayers/verify-nin, GET /cases/queues/{queueName}, POST /cases/{id}/approvals, the entire /api/v1/hr/* group (staff, leave, wallet, loans, payroll, pay grades), and /api/Security/* (public-key, status, toggle). These represent implementation additions beyond what the prompt specified.
